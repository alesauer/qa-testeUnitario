Como Baixar, Descompactar e Abrir o Apache JMeter

O Apache JMeter não precisa de instalação tradicional: basta ter o Java na máquina, baixar o arquivo compactado .zip, extrair em uma pasta e executar!

Página Oficial de Download do JMeter Baixar Java (JRE/JDK 17 ou 21)
1

Etapa 1: Verificar se você tem o Java instalado

Como o Apache JMeter foi construído em Java, ele precisa que o Java Runtime Environment (JRE) ou JDK (versão 8 ou superior, recomendada 17 ou 21) esteja instalado no seu computador.

Como testar no seu computador:

Abra o PowerShell ou o Prompt de Comando (CMD) e digite:

java -version
✅ Se aparecer algo como:
openjdk version "17.0.x" ou java version "21.x"
Tudo certo! Pode ir direto para a Etapa 2.
❌ Se aparecer a mensagem:
'java' não é reconhecido como um comando interno...
Você precisa instalar o Java! Siga abaixo:
Como instalar o Java no Windows rapidamente:
  1. Acesse https://adoptium.net/temurin/releases/ (Eclipse Temurin - Java Oficial Gratuito).
  2. Escolha Java 17 (LTS) ou Java 21 (LTS) para Windows x64 e baixe o instalador .msi.
  3. Abra o arquivo baixado e clique em Avançar ➔ Instalar até concluir.
  4. Feche seu terminal e abra novamente para testar java -version.
2

Etapa 2: Baixar o arquivo ZIP do Apache JMeter

Acesse a página de downloads da Fundação Apache:

Download Oficial do JMeter (v5.6.3): jmeter.apache.org/download_jmeter.cgi
⚠️ ATENÇÃO NA ESCOLHA DO ARQUIVO:
Na seção Binaries (Binários), clique no link do arquivo apache-jmeter-5.6.3.zip (ou a versão estável mais recente).
Não baixe a seção "Source", pois ela contém apenas código-fonte não compilado.
3

Etapa 3: Descompactar o arquivo no seu computador

Após o download do arquivo apache-jmeter-5.6.3.zip terminar:

  1. Localize o arquivo baixado na sua pasta Downloads.
  2. Clique com o botão direito no arquivo apache-jmeter-5.6.3.zip e selecione Extrair Tudo... (ou Extract All...).
  3. Escolha uma pasta de fácil acesso no seu computador.
    Exemplos recomendados:
    • C:\jmeter
    • C:\Users\seu_usuario\Downloads\apache-jmeter-5.6.3
    💡 Dica de ouro: Evite extrair dentro de pastas protegidas como C:\Arquivos de Programas para não ter problemas de permissão.
4

Etapa 4: Como Abrir a Interface Gráfica do JMeter

🪟 No Windows:
  1. Abra a pasta onde você descompactou o JMeter.
  2. Entre na subpasta bin.
  3. Procure o arquivo executável jmeter.bat (pode aparecer apenas como jmeter do tipo Arquivo de Lote do Windows).
  4. Dê duplo clique nele.
  5. Uma janela preta do Prompt abrirá (não feche ela!) e, em alguns segundos, a janela oficial do JMeter se abrirá.
🍎 🐧 No Linux / Mac:
  1. Abra o terminal e navegue até a pasta: 
    cd /caminho/apache-jmeter-5.6.3/bin
  2. Dê permissão e execute: 
    chmod +x jmeter.sh
./jmeter.sh
5

Dicas e Resolução de Dúvidas Frequentes

❓ O terminal abre e fecha na mesma hora ao clicar em jmeter.bat:

Isso significa que o Java não está instalado ou o Windows não encontrou o executável do Java. Instale o Java pela Etapa 1 e reinicie o computador.

❓ As letras estão muito pequenas na minha tela:

No JMeter, clique no menu superior Options ➔ Zoom In (ou use atalho Ctrl + +) para aumentar a interface.

❓ Como colocar a interface em Português ou Inglês:

No menu superior do JMeter, vá em Options ➔ Choose Language ➔ Portuguese (Brazil) ou English.
